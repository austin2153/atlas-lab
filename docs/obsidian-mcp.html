Obsidian MCP

A self-hosted MCP server that lets every Claude app read and write the notes vault. Claude reaches it through an outbound-only Cloudflare tunnel; Syncthing keeps the same vault on the server, the Mac and the phone over the LAN.

Claude path Sync path

Claude path

Claude's requests come from Anthropic's cloud to Cloudflare over HTTPS, then down the tunnel that cloudflared holds open from inside the lab. Nothing at home accepts inbound connections from the internet.

Sync path

Syncthing keeps the same vault on the server, the Mac and the phone. It never touches Cloudflare: the Mac and phone sync directly with the server on the LAN.
